## Download

### [ahmed-mili.github.io/neo-quiz](https://ahmed-mili.github.io/neo-quiz/)

- **Obsidian plugin**: install [BRAT](https://obsidian.md/plugins?id=obsidian42-brat), *Add Beta Plugin*, paste `https://github.com/ahmed-mili/neo-quiz`, enable **Neo Quiz**.
- **Try it**: paste [demo-template.md](demo-template.md) into a note.

## How it works

A quiz is a ` ```quiz-blocks ` code block in a Markdown note. Neo Quiz renders it as an interactive form, lets you edit it in place, schedules your reviews, and writes new quizzes with Claude Code, Codex or Ollama, through your own CLI session: no API key, ever.

## Features

- Eight question types: single, multiple, text, command line, ordering, matching, fill in the blanks, numeric
- Comprehension quizzes: one document, several questions
- Exam mode with timer and auto-submit
- Spaced review: what is due today, from an append-only log shared by the app and the plugin
- A quiz page: questions on the left, the current one on the right, editor in place
- AI generation from your notes and PDFs, with the model and effort shown on the quiz
- LaTeX everywhere, MathLive equation editor
