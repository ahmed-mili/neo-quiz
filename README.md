Neo Quiz turns your notes into interactive quizzes, generated by the AI tools you already have. Windows, Linux, and Obsidian.

[Download](https://ahmed-mili.github.io/neo-quiz/) • [Obsidian plugin](docs/guide/install.md#obsidian-plugin) • [Documentation](docs/guide/install.md) • [Release Notes](https://github.com/ahmed-mili/neo-quiz/releases)

## What you get

- `App` - Read, review, edit and generate quizzes from any folder of Markdown notes. Updates itself.
- `Plugin` - Play the same ` ```quiz-blocks ` blocks inside Obsidian, right where the notes live.
- `Generation` - Claude Code, Codex or Ollama, through your own CLI session. No API key, ever.
