Build de test Windows

Ce build contient le nouvel installeur Neo Quiz avec les étapes de préparation, téléchargement, installation et démarrage refaites.

Télécharger le build de test

GitHub fournit ce build sous forme de fichier ZIP. Extrayez-le puis, pour tester l’interface française, renommez Install-NeoQuiz.exe en Install-NeoQuiz-fr.exe avant de le lancer. Cet artefact de test est temporaire et sera remplacé par la prochaine release Windows.
