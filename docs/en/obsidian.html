Neo Quiz for Obsidian

One command installs the plugin in your vault, or creates one.

Windows (PowerShell)

irm https://ahmed-mili.github.io/neo-quiz/install.ps1 | iex

Linux

curl -fsSL https://ahmed-mili.github.io/neo-quiz/install.sh | bash

Already using BRAT? Install in one click.

What the command does

  1. Reads your Obsidian vaults and lets you pick one (or creates a new one, C:/Neo Quiz).
  2. Downloads the latest plugin release from GitHub and enables it.
  3. Opens Obsidian on that vault.
